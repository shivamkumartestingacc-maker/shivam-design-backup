# Shivam's portfolio

A static site: no build step, no dependencies. Everything (sky, sea, windmill, clouds, planes, light leaks) is drawn in code inside `index.html`.

## Deploy on Vercel

1. Unzip, then either drag the `shivam-portfolio` folder into vercel.com/new, or run `npx vercel` inside it.
2. Framework preset: **Other**. Leave build command and output directory empty.

## Files

- `index.html`: the whole site: the painted coast with live sky, seasons, day/night, apples, bees and draggable boats and planes; the prism hero; the work bento with sticky category tabs; the bottom dock nav; and the footer desk (thesis flip book, CV, Config 2026 card, contact cards).
- To finish: fill in `CONTACT` near the end of `index.html` (email, phone, LinkedIn, X, Behance, and `config` for the Config 2026 LinkedIn post).
- `archive/portfolio-v2.html`: the earlier full-page version with the bento work grid, kept for reference (not linked).
